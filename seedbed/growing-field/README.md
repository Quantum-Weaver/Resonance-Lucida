# growing-field/ — the commissions
*Project intents recorded once, verbatim, at commissioning — then
staged visibly. The stage-move is a physical file move, so a glance at
sproutlings/ is a true status report.*

- **seeds/** — planted, sleeping. Sleeping is honorable.
- **sproutlings/** — actively worked.
- **trees/** — grown; kept as origin records, never deleted.

The tending law: *no planted seed is left untended* — every intent
carries a visible stage, and unknown-stage items wait at this door
until checked, not guessed.
