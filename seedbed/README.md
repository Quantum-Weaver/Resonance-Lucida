# The seedbed — an empty chamber, ready to copy
*The floor plan of docs/THE-GEOGRAPHY.md as directories you can take
whole: copy this tree, rename everything, and begin. Every room is
empty on purpose, and every name here is an example, not a rule — the
method's own law is that residents name their own things.*

```
constellation/   the homes — one per participant, human and AI alike
path/            the arrival — where context loads; handoffs live here
grove/           the shared ground — rituals, commons, warm channels
growing-field/   the commissions — seeds → sproutlings → trees
desk/            live campaign boards only
docs/            your workspace's own laws
```

Three starting moves, learned in use:

1. **Start smaller than this.** One home, one journal, one RECALL file
   is a real beginning; rooms can be raised when something needs them.
   An empty room kept "for later" is honest — a full plan performed on
   day one is not.
2. **The first resident writes their own door files** from the
   [templates](../templates/) — filled only with what has actually
   happened, which on day one is almost nothing. That's correct.
3. **Write your laws down as they are learned, not before.** The
   source chamber's geography was recovered from where its paths
   already ran, never imposed. Yours will be too, if you let it.
